# 국방예산 인사이트 대시보드

`index.html`을 Chrome 또는 Edge에서 열면 바로 사용할 수 있습니다. 서버 설치, 인터넷 연결, 외부 차트 라이브러리가 필요하지 않습니다.

## 기능

- 부문과 회계구분을 조합하여 필터링: 4개 지표와 8개 그래프, 상세 표가 함께 갱신됩니다.
- 부문별 연도 비교, 회계별 도넛, 프로그램 트리맵, 부문·회계 히트맵, 주요 프로그램 비교, 증감 순위, 성장률 산점도, 순재원 워터폴.
- 그래프 위에 마우스를 올리거나 Tab 키로 항목을 선택하면 상세 수치를 확인할 수 있습니다.
- 상세 표의 검색·열 정렬 및 현재 표의 CSV 내려받기. 검색은 상세 표에만 적용됩니다.
- 모바일 화면 지원. 작은 화면에서는 그래프를 좌우로 스크롤하여 읽을 수 있습니다. 회계구분 목록은 선택한 부문에 맞게 변경됩니다.

## 데이터와 계산

원본: 상위 폴더의 `프로그램별_재원_2026_2027.xlsx`, `프로그램별 재원` 시트의 32개 항목. 생성 시점의 데이터가 `data.js`에 저장되어 있으므로 엑셀 변경이 자동 반영되지는 않습니다.

- 금액 단위: 억원. KPI의 예산 규모는 조원도 함께 표시합니다.
- 순재원: 선택한 항목 금액을 내부거래 차감액까지 포함하여 합산.
- 증감: 2027년 − 2026년.
- 증감률: 증감 ÷ 2026년. 기준액이 0이면 표시하지 않습니다. 음수 차감액의 증감률도 엑셀과 같은 산식입니다.
- 구성비와 트리맵: 양수 재원만 사용. 산점도: 두 연도 금액이 모두 양수인 프로그램만 표시.
- 원본의 프로그램 금액 합계는 2026년 677,039억원, 2027년 732,776억원입니다. PDF 총재원 표와 각각 1억원 차이가 있으며 원본을 임의 보정하지 않았습니다.
- 프로그램별 금액으로 재계산한 증감률은 원문 PDF의 증감률과 반올림 차이가 있을 수 있습니다.

## 파일 구성

- `index.html`: 대시보드 페이지
- `styles.css`: 반응형 디자인
- `app.js`: 필터, 계산, SVG 차트, 검색, 정렬, 내보내기
- `data.js`: 엑셀에서 추출한 데이터

폴더 전체를 함께 보관하면 다른 PC에서도 사용할 수 있습니다.
